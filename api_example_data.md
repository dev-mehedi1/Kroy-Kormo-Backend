## 8. Development Guidelines
- **ID Format**: All IDs are standard UUID/GUID v4 strings.
- **Date Format**: ISO 8601 (`YYYY-MM-DDTHH:mm:ssZ`).
- **Currency**: Numeric values with up to 2 decimal places.
- **Authorization**: Protected endpoints require a `Bearer <JWT_TOKEN>` in the `Authorization` header.
- **Localization**: All text is returned in English (default), with slugs optimized for SEO-friendly URLs.
